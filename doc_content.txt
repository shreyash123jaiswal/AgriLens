AGRILENS AI — COMPLETE ANTIGRAVITY DEVELOPMENT SPECIFICATION
Hackathon Project • AI-Powered Geospatial Smart Agriculture Platform
1. Project Identity
Project Name: AgriLens AI
Tagline: See your land. Predict your yield. Grow smarter.
Project Type: Hackathon web application combining geospatial data, satellite imagery, weather/climate information, soil information, machine learning, and an AI farm advisor.
2. Problem Statement
Build an AI-powered smart agriculture system that leverages geospatial data like satellite imagery, climate patterns, and soil conditions to help farmers make better decisions. The solution should monitor land, predict crop yield, and recommend optimal farming strategies based on location-specific insights, ultimately improving productivity and reducing risks in agriculture.
3. Core Solution
AgriLens AI is a location-aware agricultural decision-support platform. A farmer selects or draws the boundary of a farm on an interactive map. The system obtains or simulates location-specific satellite, weather, climate, soil, and historical agricultural information. An analytics/ML pipeline calculates vegetation indicators such as NDVI, assesses crop suitability, predicts yield, identifies risks, and converts the results into practical recommendations.
Core pipeline:
Farm Location → Satellite + Weather + Soil + Historical Data → Feature Engineering → ML Models → Risk/Yield/Crop Analysis → AI Farm Advisor → Actionable Recommendations

5. Features
Farm Selection: Search a place, click/draw a polygon, calculate approximate area, save coordinates.
Farm Health: Aggregate vegetation, soil, weather, and risk signals into an understandable health score.
Satellite Analysis: Display satellite/vegetation layer or prepared imagery; calculate/display NDVI trend where supported.
Weather Intelligence: Temperature, humidity, rainfall, forecast, wind, historical/expected rainfall where available.
Soil Intelligence: pH, N, P, K, moisture, organic carbon/soil type where available.
Crop Suitability: Rank suitable crops using ML/rules and show reasons rather than only a score.
Yield Prediction: Predict yield in tonnes/hectare using crop, climate, soil, vegetation, and historical features.
Risk Analysis: Estimate drought, flood/heavy rain, crop stress, and disease/pest risk when inputs support it.
AI Farm Advisor: Generate data-grounded recommendations such as irrigation timing, crop choice, monitoring, and fertilizer considerations.
Historical Trends: Show NDVI, rainfall, temperature, and yield trends when historical data is available.

17. ML Design
Model A — Crop Suitability
Input features: soil pH, N/P/K, moisture, temperature, rainfall, humidity, NDVI, crop requirements, location/climate features. Output: suitability score/class for candidate crops.
Model B — Yield Prediction
Recommended starting model: XGBoost Regressor. Inputs: crop, farm area, rainfall, temperature, soil values, NDVI, historical yield and other available features. Output: tonnes/hectare.
Model C — Risk
Use classification/regression/rule-assisted scoring depending on available labelled data. Do not fabricate model accuracy. If trained data is synthetic or demo data, label the results as prototype/demo estimates.
Important: build a clean preprocessing pipeline, train/validation split, feature handling, model persistence, and inference functions. Expose inference through FastAPI.
18. NDVI
Formula: NDVI = (NIR - Red) / (NIR + Red)
Use NDVI as a vegetation-health feature. If actual satellite bands are unavailable during the demo, use prepared sample NDVI time-series data and clearly label it as demo data rather than pretending it is live imagery.
19. AI Farm Advisor
The LLM must receive structured analysis results and generate concise recommendations. It should not invent measurements. Recommendations should reference the available inputs.
Example input: soil moisture 63%, rainfall forecast 42 mm, NDVI 0.72, temperature 29°C.
Example output: 'Rain is expected soon and soil moisture is moderate. Consider postponing irrigation and rechecking moisture after rainfall.'
Add a visible disclaimer: 'AI recommendations are decision-support estimates and should be validated with local agricultural experts/field observations.'

24. Visual Design Direction
Modern agritech dashboard.
Primary visual language: natural greens with neutral backgrounds and restrained accent colors.
Avoid excessive gradients, glassmorphism, or gaming aesthetics.
Use cards with clear hierarchy, subtle borders/shadows, readable typography.
Use map/satellite imagery as a visual focal point.

25. Security and Reliability
Do not expose API keys in React.
Validate all incoming coordinates and polygons.
Validate numeric ranges for soil/weather features.
Handle external API timeouts gracefully.
Add CORS configuration.
Return structured error responses.
Never claim live data or model accuracy without evidence.
Keep model files and datasets outside the frontend.
